Kyushu University, Department of Aeronautics and Astronautics

Apr 2026 – Present

Undergraduate Researcher · Advisor: Prof. Kenichi Abe

  • Undergraduate Thesis: A Study on Nonlinear SGS Models for LES Based on the Tensor Basis Neural Network Using Machine Learning
  • Achieved accuracy comparable to using all 10 of Pope's tensor bases with only the first four (T(1)–T(4)) in a posteriori simulations of channel flow at Reτ = 395, reducing velocity overprediction primarily in the buffer and outer layers relative to conventional isotropic models.
  • Investigating T(6) as a potential extension of conventional strain-rate-tensor-based SGS models, motivated by its linear dependence on the strain-rate tensor in laminar channel flow.
  • Reduced mean-velocity relative L2 error against DNS from 19.54% with a conventional isotropic model to 3.73% by learning only the coefficient of the isotropic tensor T(6), without incorporating anisotropic tensor terms, using a composite loss function that equally evaluates both the normalized anisotropy tensor and physical stress scale instead of the standard loss function evaluating only the SGS stress anisotropy tensor.
